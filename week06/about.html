About Summoner's Index

This website was created as a project for WDD 231. The goal was to build a dynamic, modern web application using vanilla JavaScript, HTML, and CSS. It demonstrates key web development skills including fetching data from a JSON file, dynamic DOM manipulation, using local storage to save user preferences, and building a fully responsive, mobile-first design.
